04 · Exemplo Resolvido
🧮 EXEMPLO RESOLVIDO — clique para ver a resolução
A IDE Arduino não reconhece a porta COM da placa conectada via USB. Liste os passos de verificação, em ordem.
  1. Verificar se o cabo USB esta bem conectado (tente outro cabo/porta)
  2. Em Ferramentas -> Placa, selecionar 'Arduino Uno'
  3. Em Ferramentas -> Porta, selecionar a porta COM correta
  4. Se ainda não aparecer, reinstalar o driver CH340/FTDI do computador
✅ Resposta: Cabo -> Placa -> Porta -> Driver
