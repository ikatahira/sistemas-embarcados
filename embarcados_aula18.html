05 · Atividades Práticas
01
EX-01 · EXERCÍCIO
Montagem Física Completa
⏱ 40 min 🎯 Montar todos os componentes do projeto
Montar fisicamente todos os componentes planejados no chassi/protoboard: motores, sensores e display, conforme o escopo definido.
RESOLUÇÃO PASSO A PASSO — clique para ver
  1. Separem todos os componentes listados na ficha de escopo.
  2. Montem primeiro a base (chassi + motores), depois os sensores, depois o display/LEDs.
  3. Conferam cada conexão contra o diagrama planejado antes de energizar.
  4. Fixem bem os fios (fita adesiva/abraçadeiras) para evitar desconexões durante o teste.
02
EX-02 · EXERCÍCIO
Testes Unitários dos Subsistemas
⏱ 30 min 🎯 Validar cada subsistema isoladamente antes da integração
Testar isoladamente cada subsistema (motores, sensores, display) antes de integrá-los em um único código, evitando erros difíceis de depurar na integração final.
RESOLUÇÃO PASSO A PASSO — clique para ver
  1. Testem os motores isoladamente, sem os sensores no código: eles giram nos sentidos esperados?
  2. Testem os sensores isoladamente, exibindo as leituras no Serial Monitor.
  3. Testem o display/LEDs isoladamente, exibindo/acendendo valores fixos.
  4. Anotem qualquer subsistema que não funcionou como esperado, para corrigir antes da integração.
